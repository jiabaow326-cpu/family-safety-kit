# 家安小卡｜家庭反詐應急計畫

一個離線優先、免註冊的家庭應急小卡 Web App。使用者可以預先設定可信任聯絡人、獨立查證方式與家庭暗號；遇到催促匯款、保密、提供驗證碼或分享螢幕等要求時，按清單停止操作並查證。

## 使用方式

### 本機預覽

需要 Node.js 18 或更新版本，不需安裝 npm 套件：

```bash
node server.mjs
```

在瀏覽器開啟 `http://localhost:4173`。首次開啟後，服務工作者會快取頁面檔案，可在同一瀏覽器離線開啟。也可以把資料夾直接發布到 GitHub Pages 等靜態網站服務。

### 使用流程

1. 在「設定應急卡」填入一至三位已存於通訊錄的聯絡人。
2. 勾選家庭可用的獨立查證方式，並選擇遇到可疑要求時的第一步。
3. 暗號欄位為選填；不要使用密碼、生日、地址、銀行資料或驗證碼。
4. 到「情境練習」練習三種常見的催促話術。
5. 打開「我的小卡」列印、另存 PDF、下載 JSON 備份或複製提醒給家人。

## 功能

- 手機、平板、桌面自適應版面
- 本機 `localStorage` 自動儲存和清除資料
- 3 組反詐情境練習，即時解釋安全選項
- 列印友善的應急卡與 JSON 備份
- Service Worker 靜態快取；沒有帳號、後端、分析追蹤或第三方程式庫
- 載入警政署 165 全民防騙網等官方資源連結

本作品使用 Codex（AI 開發工具）協助完成設計、程式與內容整理。

## 隱私與安全

輸入的稱呼、電話、暗號只寫入目前瀏覽器的本機儲存，不會由 App 上傳。若在公用或共用裝置使用，請不要輸入個人資料，離開前清除本機資料。JSON 備份包含使用者自行輸入的資訊，下載後應自行妥善保管。請勿把暗號當作金融密碼或帳戶驗證方式。

App 不會判斷來電真假，也不會替使用者執行轉帳、停卡或報案。台灣地區可透過警政署 165 全民防騙網查詢反詐資訊；有緊急人身安全疑慮時請使用當地緊急服務。台灣以外地區請查詢所在地的官方求助管道。
